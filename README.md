# AETHER — Animated Creative Studio Website

A premium single-page creative studio website built with pure HTML, CSS and JavaScript. No frameworks, no build step — just silky-smooth UI/UX animations.

## ✨ Features

- **Cinematic preloader** with progress counter
- **Custom magnetic cursor** with hover states
- **Kinetic hero text** with staggered reveal
- **Animated gradient orbs** and grain overlay
- **3D tilt cards** with glare effect
- **Scroll-triggered reveals** (fade, slide, blur)
- **Animated stat counters**
- **Infinite marquee** band
- **Fluid blob-to-grid** portfolio hover
- **Full responsiveness** + reduced-motion support

## 🚀 Quick Start

```bash
# serve locally
npx serve .
# or just open index.html in a browser
```

## 🧱 Stack

- HTML5 semantics + ARIA states
- CSS custom properties, keyframes, `clip-path` morphing
- Vanilla JS (IntersectionObserver, requestAnimationFrame, pointer events)
